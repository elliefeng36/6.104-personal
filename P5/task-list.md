# Task list for user testing

| Task | Instructions | Reasoning |
| ---- | ------------ | --------- |
| Make new task | Create a new task to schedule a meeting with Bob. | Creating a new task is one of the most important and most common actions, so I want to make sure it is as simple, intuitive, and quick to complete as possible. |
| Edit task | Edit the "schedule meeting with Bob" task to have a due date of Friday and a duration of 10 minutes. | Since one of the ease-of-use features of this app is making a barebones task while on the fly and then filling out the details later, it's important to test that editing a task is quick to find and complete for the user. |
| Complete task | Complete the "submit drop form" task. | Another very common action in this app is completing a task, so once again, it is very important to verify that completing a task is extremely simple and intuitive. |
| Delete task | Delete the "buy soap" task. | While deleting is a rarer action, it is still important to make sure users can delete a task if they make one on accident and are able to traverse the confirmation popup. |
| Make recurring task | Create a task to water the plants that takes five minutes and recurs once a week | One of the key differentiators of this app is that users can set recurring tasks that are automatically readded to the tasklist, so making sure the process of creating a recurring task is intuitive and easy to use is vital to the usefulness of the app. |
| Suggest tasks | Generate a suggested task for if you have 15 minutes of free time. | Another feature that sets this app apart from others is its ability to suggest tasks to complete, which reduces decision paralysis. So, I want to make sure this feature is easy to understand and operate. |
| Sort tasks | Find the task that is due the soonest. | Because task lists can often get long and overwhelming, it's important to make sure the features that make task lists easier to deal with, such as sorting, make sense to use. |
| Filter tasks | Find all the tasks that can be done in less than 20 minutes. | Again, since a task list can get long, we want to ensure that users are able to use features that make task lists easier to read and process. |
